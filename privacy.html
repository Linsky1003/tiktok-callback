Datenschutzerklärung

Stand: 20.08.2026

Diese Erklärung betrifft ein privates, nicht-kommerzielles Softwareprojekt eines Einzelentwicklers, das Videos automatisiert auf einen einzelnen, selbst kontrollierten TikTok-Account veröffentlicht.

1. Welche Daten werden verarbeitet

  • TikTok-OAuth-Zugriffs- und Refresh-Token des verbundenen Accounts (ermöglichen das Veröffentlichen von Videos im Namen dieses Accounts)
  • Video-Dateien, die vor der Veröffentlichung verarbeitet werden
  • Öffentlich über die Twitch-API abrufbare Metadaten (z.B. Clip-Titel, Aufrufzahlen) zur Auswahl der Inhalte

2. Speicherung

Alle Daten werden ausschließlich lokal auf einem vom Betreiber selbst kontrollierten Rechner bzw. Server gespeichert. Es findet keine Weitergabe an Dritte statt.

3. Zweck der Verarbeitung

Die Daten werden ausschließlich genutzt, um automatisiert Videoinhalte auf dem verbundenen TikTok-Account zu veröffentlichen. Es findet kein Tracking, keine Profilbildung und keine Weitergabe zu Werbezwecken statt.

4. Löschung

Zugriffstoken können jederzeit über die TikTok-Kontoeinstellungen (App-Berechtigungen widerrufen) entzogen werden. Lokal gespeicherte Daten können auf Anfrage gelöscht werden.
